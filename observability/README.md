# Where the grid cannot see

Instrument 02: where India's distribution grid is least observable, set against where rooftop solar is
being connected.

**Status: data survey in progress.** Following the brief, nothing is built until the survey has
answered the question the design depends on. That question is the finest geography at which
smart-meter penetration and feeder telemetry are published. If the answer is state level only, a
national map would be too coarse to say anything, and the project becomes a single-city study of
Bengaluru or Delhi instead.

The survey and its cached sources live in [`survey/`](survey/).
